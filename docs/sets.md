# Item Sets and Set Bonuses

## How sets work

- **Every set activates at 2 pieces.** There is no 4-piece tier.
- Set bonuses consume **Modifier slots**, *not* gem sockets. You pay 2 modifier slots per set —
  your gem sockets are untouched.
- You can run **two sets from Capstone (3-boss) dungeons and two sets from Adventure (1-boss)
  dungeons** simultaneously. The practical endgame target is **2 sets = 4 pieces**.
- Set pieces drop from dungeons run in **Challenge or Eternal** modes.

## Choosing your two sets

**Slot one is always Seal of the Heskyr.** Nothing else scales like +25% Gem Power, and it is the
enabler for every focused single-colour gem build in this repo.

**Slot two, by role:**

| Role | First choice | Reasoning | Alternative |
|---|---|---|---|
| **Tank** | Sinthara's Veil | +10% magic DR is the scarcest defensive stat in dungeons | Draconic Fury for threat; Torment of Bael'Aurum for the cheat death |
| **Healer** | Haunting Lament | +4% Spirit and +15% max mana directly extend how long you can sustain | Draconic Deceit if threat is a problem; Torment of Bael'Aurum for safety |
| **DPS** | Death's Grasp | +4% Spirit plus execute damage, the cleanest throughput set | Draconic Might for burst ceiling; Dark Prophecy for haste-scaling builds |

**Universally defensible fallback:** Torment of Bael'Aurum. +4% primary stat is never wasted and
the sub-20% heal converts deaths into survivals during progression pushes.

**Tuzari Grace** deserves a mention out of tier: +20% movement speed is a *route* stat. In timed
Champion +4 and beyond content it can be worth more than a throughput set on pull-heavy dungeons.
