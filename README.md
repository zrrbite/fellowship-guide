# Fellowship — Class Progression Compendium

Optimal specs, talents, gems, traits, items and set bonuses for **every hero in Fellowship**
(Chief Rebel / Arc Games), current as of **Early Access Season 3 — "Rise of the Heskyr"**.

The repository answers one question per hero: **what should this character focus on next?**

## How to use this repo

1. Read [`docs/progression.md`](docs/progression.md) once — it defines the league ladder and the
   item-level gates that everything else hangs off.
2. Open your hero's file. Every hero page ends with a **Focus Next** ladder keyed to your
   current league, so you can jump straight to the line that matches where you are.
3. Cross-reference [`docs/gems.md`](docs/gems.md) and [`docs/sets.md`](docs/sets.md) when you have
   loot decisions to make.

## Universal truths (apply to all twelve heroes)

- **Item level beats stat optimisation** until you are deep in Eternal. Main stat drives damage,
  healing *and* survivability simultaneously. Equip the higher ilvl piece.
- **Seal of the Heskyr (+25% Gem Power) is best-in-slot for every hero.** It is the single highest
  leverage set in the game because it converts into gem-track ranks you could not otherwise reach.
- **14 talent points total.** They are earned from dungeon completions and rating; respec is free
  between runs. There is no wrong permanent choice — retune per dungeon.
- **Four gem sockets**, guaranteed on Epic+ Cloak, Wrists and both Rings. A Legendary adds a fourth.
- **Imbued Essence modifiers grant +100 Gem Power without a socket**, stacking to +200. These are
  how focused single-colour builds reach rank 10.

> ⚠️ Fellowship is in Early Access and is balanced aggressively between seasons. Treat every
> build here as a strong default, not scripture. See [`SOURCES.md`](SOURCES.md) for re-verification.
